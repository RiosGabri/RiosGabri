# Olá, pessoal! 👋

Sou **Gabriel Parméra (RiosGabri)**, estudante do terceiro período de **Ciência da Computação**, com foco em **desenvolvimento backend**. Trabalho principalmente com Python e Django, com experiência também em sistemas de baixo nível em C e em projetos full-stack menores.

---

## 🚀 Sobre mim

- Atuei como Tech Lead durante 3 meses no **ARCA Ensina**, liderando o desenvolvimento do backend em Django REST Framework.
- Vencedor da hackathon do Cesar + Aries (com apoio da prefeitura) com a solução **Jardim Sentinela**, projeto de Tecnologias Comunitárias para risco de água e calor.
- Tenho experiência pontual com C em nível de sistemas, incluindo o desenvolvimento de um jogo com física (Chipmunk2D + Raylib), apresentado na Mostra Tech Design.
- Experimentei com desenvolvimento de jogos digitais e práticas colaborativas usando Git.
- Também construo projetos full-stack menores para explorar front-end e integração completa.
